01

文法核心 GRAMMAR CORE

N4 80% 出自呢度
文型 PATTERN接續・意思 / 區別例句 / 香港話提示
01〜そうだ【樣態】
Vます+そう / イ形+そう / な形+そう
看起來...、快要...
雨が降りそうです。/ このケーキはおいしそうです。
02〜ようだ / 〜らしい
普通形 + ようだ / らしい
ようだ=主觀推測 らしい=客觀聽說/典型
彼は来ないようだ。/ 彼は来ないらしい。
03〜ておく
Vて+おく
事先準備、放著不管
旅行の前に切符を買っておきます。
04〜てしまう
Vて+しまう
不小心、徹底完成、遺憾
財布を忘れてしまった！
05〜てくる / 〜ていく
Vて+くる/いく
變化開始往現在 / 往未來持續
だんだん暖かくなってきた。/ 持っていきます。
06可能形
書く→書ける / 食べる→食べられる
能夠… 能力/許可
漢字が読めます。/ 一人で行けますか。
07〜ようと思っている
意向形+と思っている
打算…（持續的意圖）
来年、日本へ行こうと思っています。
08〜たら / 〜ば / 〜と / 〜ても
条件分歧
たら=假設/發現 ば=純條件 と=必然 ても=即使
安かったら買います。/ 行ってもいいです。
09〜なければ/なくてもいい
Vない+ければならない / なくてもいい
必須 / 不必
行かなければなりません。/ 来なくてもいいです。
10〜ために / 〜ように ★必考
為目=意志動詞 / よう=可能·否定·無意志
為目的而…
日本へ行くために貯金する。/ 見えるように大きく書く。
11〜てあげる/くれる/もらう
授受：あげる→外 くれる→內 もらう→受取
給予·接受 人際方向
友達に教えてあげる。/ 先生が教えてくれた。
12使役 させる / 被動 られる
行かせる / 行かれる / 食べさせられる
使役=讓做 被動=被… 使役被動=被迫
母は私に野菜を食べさせた。/ 兄にケーキを食べられた。
13〜ところだ / 〜ばかり
Vる/ている/た+ところ / Vたばかり
正要/正在/剛完 / 剛剛才
今から出かけるところです。/ 食べたばかりです。
14〜はずだ / 〜べきだ / 〜わけだ
普通形+はず/べき/わけ
應該會/應該做/難怪…道理
彼は来るはずだ。/ 学生は勉強すべきだ。
15〜すぎる / 〜やすい/にくい
Vます+すぎる / やすい/にくい
過度 / 容易·難做
食べすぎた。/ このペンは書きやすい。
16〜てある vs ている
他動+てある=結果狀態 / 自動+ている
窗已開(有意) vs 窗開著(狀態)
窓が開けてある。/ 窓が開いている。
17敬語基礎
おVになる / Vていらっしゃる / 存じます
尊敬語 / 謙讓語
社長がお帰りになる。/ 存じております。
★ 授受陷阱： くれる主語係「對方→我」，あげる係「我→對方」。題目成日調轉問！
★ ため vs よう： ため前面一定係意志動詞（行く・買う）。前面係可能/否定/無意志→用ように。
★ 使役被動： 行かせられる = 被逼去。N4最鍾意考「子供の時、母に…させられた」

03

讀解技巧 READING

先睇問題！
  • ①先看問題再看文章：N4讀解時間勁趕，圈出「何・誰・いつ・なぜ」
  • ②接續詞=答案提示：しかし/でも→轉折後係重點、だから→原因結果、ところが→意外展開
  • ③題型對策：
    ・告示/張貼→先睇日期時間地點
    ・Email→誰寫給誰？目的係咩？
    ・時刻表→「～までに」「～から」圈起
  • 💡 香港學生優勢： 漢字多識一半，但小心訓詁陷阱：勉強(べんきょう) ≠ 勉強，手紙(てがみ)=信
